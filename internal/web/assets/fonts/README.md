# Web fonts

Chakra Petch (600) and IBM Plex Sans (400, 500, 600), Latin WOFF2 subsets,
match TailShare's heading and body typography. These unmodified files were
copied from TailShare-p2p's installed @fontsource packages. Both font families
are distributed under the SIL Open Font License 1.1; their copyright notices
and full licenses are included alongside the files.

The fonts are embedded into the ts-redir binary and served locally, together
with the stylesheet. No external font or CSS service is required.
